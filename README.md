# telegram_colorizer_bot — колоризация ч/б фотографий

Дипломный проект по Data Science (zerocoder): нейросеть раскрашивает чёрно-белое
изображение, а телеграм-бот принимает фото от пользователя и возвращает цветной вариант.

## Как это работает

1. Фото пользователя приводится к оттенкам серого.
2. Кадр масштабируется до 256×256 и переводится в пространство **Lab**:
   модель получает только канал L (яркость) и не тратит ёмкость на то, чтобы
   заново выучить контуры.
3. Улучшенный **U-Net** предсказывает два цветовых канала a и b (выход умножен на 128
   и обрезан в диапазон −128…127, как при обучении).
4. Каналы собираются обратно в Lab, переводятся в RGB и растягиваются до исходного
   размера кадра (BICUBIC).

Обучение — `model.py`: ноутбук из Google Colab, датасет с Kaggle, функция потерь MSE,
оптимизатор Adam. Вход сети — `(256, 256, 1)`, выход — два канала.

## Веса модели

В репозитории весов нет: файл на 88 МБ раздувал клон и историю. Они лежат в релизе:

- страница релиза: https://github.com/Alexsey111/telegram_colorizer_bot/releases/tag/v1.0
- прямая ссылка: https://github.com/Alexsey111/telegram_colorizer_bot/releases/download/v1.0/model.h5
- размер: 92 860 504 байт
- sha256: `d8ae091cacd57aaf5a19d56b4c5b506c09d930fbd8a48658dbbe4b223cdd31f5`

Скачать:

    python scripts/download_model.py

Скрипт кладёт файл как `model.h5` рядом с `main.py` и проверяет контрольную сумму.
`main.py` тоже умеет докачивать веса сам при первом запуске, если файла нет.
Путь и адрес можно переопределить переменными `MODEL_PATH` и `MODEL_URL`.

## Запуск

Нужен Python 3.10–3.12: TensorFlow под 3.13 ставится нестабильно.

    python -m venv .venv
    .venv\Scripts\activate                 :: Windows
    pip install -r requirements.txt
    set BOT_TOKEN=<токен от @BotFather>    :: Windows
    export BOT_TOKEN=<токен>               # Linux/macOS
    python main.py

Без `BOT_TOKEN` скрипт завершается с понятным сообщением, токена в коде нет.

## Структура

    main.py                    бот: приём фото, загрузка весов, предсказание, ответ
    model.py                   обучение модели в Colab: архитектура, датасет, графики
    scripts/download_model.py  скачивание весов из релиза с проверкой sha256

## Ограничения

- Разрешение предсказания 256×256, дальше апскейл — мелкие детали и лица теряют цвет.
- MSE как функция потерь даёт усреднённые, «приглушённые» цвета; GAN или perceptual loss
  дали бы насыщеннее, но это уже другая работа.
- Загружаются веса в формате h5 из Keras 2. Если TensorFlow 2.16+ отказывается читать файл,
  нужен `tf_keras` и загрузка через него — версия фреймворка в проекте не фиксировалась.
- Тестов нет: качество колоризации оценивалось глазами на выборке из датасета.
